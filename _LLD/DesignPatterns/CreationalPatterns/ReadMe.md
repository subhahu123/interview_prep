# Design Patterns Comparison Table

| Pattern     | Focus                             | Use When                                           | Real-World Example                                  |
|-------------|-----------------------------------|----------------------------------------------------|-----------------------------------------------------|
| Prototype   | Clone an existing object          | You need many similar objects                      | Cloning a document template or game enemy objects   |
| Builder     | Step-by-step complex construction | You build objects piece by piece                   | Building a pizza or creating a complex UI layout    |
| Factory     | Encapsulate object creation       | You choose from multiple object types              | Notification factory (Email, SMS, Push)             |
| Singleton   | Ensure a single instance          | You need exactly one global, shared instance       | Logger, Database connection, Configuration manager  |
